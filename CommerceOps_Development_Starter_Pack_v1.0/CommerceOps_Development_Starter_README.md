# CommerceOps Development Starter Pack v1.0

This pack is intended to be handed to the engineer together with the coding agent.

## Files

- `CommerceOps_Master_Specification_v1.0.docx` — product-wide architecture, engineering standards, technology baseline, spec process and Definition of Done.
- `CommerceOps_EPIC-03_Inventory_Development_Spec_v1.0.docx` — first executable Epic/Feature specification including Phase 0, INV-F03, User Stories, API/data/UI/security/test contracts and coding-agent rules.
- `CommerceOps_Master_Progress_Tracker_v1.1.xlsx` — master delivery tracker with Foundation, Epics, Features, Phase 0 Tasks and INV-F03 User Stories.
- `CommerceOps_AGENT_START_HERE.md` — concise kickoff context to give the coding agent after the specifications are available in its working context.

## Start here

1. Engineer reads the Master Spec.
2. Engineer reads the Inventory Development Spec.
3. Create/initialize the repository.
4. Give the coding agent the same two specs plus `CommerceOps_AGENT_START_HERE.md`.
5. Execute `BOOT-001..008` only to the defined stop condition.
6. Start `INV-US001` and proceed in small reviewable batches.
7. Update `CommerceOps_Master_Progress_Tracker_v1.1.xlsx` after each accepted batch.
8. Create an ADR/spec update before any material architecture, data, API or security change.
